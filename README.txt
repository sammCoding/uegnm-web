# UEGNM — Landing Page

Landing page de la campaña:
“Generación Nuevo Milenio: Formando el futuro”

## Archivos
- `index.html` — estructura y contenido.
- `styles.css` — diseño responsive.
- `script.js` — menú móvil, animaciones y año automático.
- `assets/photo-placeholder.svg` — placeholder para fotografías.
- `assets/logo-placeholder.svg` — placeholder para el logo.

## Cómo usarla
1. Abre `index.html` en el navegador.
2. Sustituye los placeholders de `assets/` por fotografías reales.
3. Para una imagen, puedes cambiar el `src` de una etiqueta `<img>`.
4. En la sección `<!-- [ VIDEO ] -->`, reemplaza el placeholder por tu video 9:16.
5. Completa `[ DIRECCIÓN ]`, `[ TELÉFONO ]`, `[ CORREO ]` y `[ REDES SOCIALES ]` cuando tengas los datos.

No se incluyen fotografías inventadas de la institución.
